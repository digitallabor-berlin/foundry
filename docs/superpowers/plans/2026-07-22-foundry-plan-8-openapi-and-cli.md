# Foundry Plan 8 — OpenAPI 3.x, Swagger UI & CLI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement OpenAPI 3.x spec generation and embedded Swagger UI using `utoipa`, export `foundry openapi --out <file>` CLI subcommand, auto-write OpenAPI spec on service startup, and add `foundry status-list` CLI subcommands for offline status list querying, modification, and token generation.

**Architecture:** Annotate Admin API handlers and models with `utoipa::path` and `utoipa::ToSchema`. Mount Swagger UI and `/api-docs/openapi.json` endpoints on the admin axum router when `swagger_ui_enabled` is true. Add `openapi` and `status-list` subcommands to clap CLI in `crates/foundry/src/cli.rs`.

**Tech Stack:** Rust (edition 2021), tokio, axum, `utoipa`, `utoipa-swagger-ui`, `foundry-core`, `foundry-issuer`, `foundry-verifier`, `clap`.

## Global Constraints

- **No panics or unwraps** in request handling or public APIs.
- **OpenAPI Accuracy:** OpenAPI 3.x JSON output generated by `utoipa` must be valid JSON matching all Admin API routes and schemas.
- **Config-Driven Swagger UI:** Swagger UI served at `/swagger-ui` on the admin listener, respect `swagger_ui_enabled` setting in `AdminConfig`.
- **Status List CLI:** Offline CLI status-list management interacting directly with SQLite storage.

- [ ] **Step 1: Mount Swagger UI and OpenAPI JSON on admin router in `crates/foundry/src/server.rs`**

```rust
pub fn admin_router(state: AppState, api_key: AdminApiKey) -> Router {
    let mut unauthenticated = Router::new()
        .route("/health", get(health))
        .route("/ready", get(ready))
        .route("/api-docs/openapi.json", get(openapi_json_handler));

    if state.config.server.admin.swagger_ui_enabled {
        unauthenticated = unauthenticated.merge(
            utoipa_swagger_ui::SwaggerUi::new("/swagger-ui")
                .url("/api-docs/openapi.json", crate::openapi::ApiDoc::openapi())
        );
    }

    let unauthenticated = unauthenticated.with_state(state.clone());

    let authenticated = Router::new()
        .route("/admin/issuance/offers", post(create_offer_handler))
        .route("/admin/verification/requests", post(create_verification_handler))
        .route("/admin/verification/requests/:id", get(get_verification_handler))
        .route_layer(middleware::from_fn_with_state(api_key, require_api_key))
        .with_state(state);

    unauthenticated.merge(authenticated)
}

async fn openapi_json_handler() -> (axum::http::HeaderMap, String) {
    let mut headers = axum::http::HeaderMap::new();
    headers.insert(axum::http::header::CONTENT_TYPE, "application/json".parse().unwrap());
    (headers, crate::openapi::generate_openapi_spec())
}
```

Annotate admin handlers with `#[utoipa::path(...)]` for OpenAPI path discovery.
